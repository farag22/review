# Crazy Poker Online

نسخة MVP قابلة للتجربة من لعبة بوكر اجتماعية عربية، مبنية بواجهة React/Vite وخادم Node/WebSocket مستقل، مع غلاف Capacitor جاهز للبناء على Android.

## التشغيل المحلي

```bash
npm install
npm run start
```

ثم افتح `http://localhost:8787` في متصفحين أو جهازين على نفس الرابط. اكتب اسمين مختلفين، أنشئ غرفة من العميل الأول، ثم انضم من العميل الثاني. تبدأ اليد تلقائيًا عند وجود لاعبين متصلين، وتنفذ الأفعال على الخادم.

للتطوير الأمامي فقط استخدم `npm run dev`، وللتجميع استخدم `npm run build`.

## ما يعمل في MVP

- طاولة بيضاوية زرقاء بإطار خشبي، 8 مقاعد، أوراق، pot، رهانات، وأزرار Call/Raise/Fold/All-in.
- غرف عامة وخاصة برمز، ومزامنة فورية بين لاعبين عبر WebSocket.
- Texas Hold'em مبسط على الخادم مع blinds 25/50 ومراحل preflop/flop/turn/river.
- evaluator لأفضل 5 أوراق وحساب الفائز وتقسيم pot.
- رصيد وإحصائيات أساسية محفوظة في `server/store.json` للنسخة الأولية.

## ما قبل الإنتاج

التخزين الحالي ملف JSON مقصود لتسهيل الاختبار، وليس بديلاً عن PostgreSQL. قبل الإطلاق يجب إضافة تسجيل حسابات وجلسات آمنة، PostgreSQL وRedis عند التوسع، لوحة إدارة بصلاحيات، rate limiting ومراقبة، نسخ احتياطية، وحماية من الغش. كما يجب تثبيت ما إذا كانت القواعد النهائية هي Texas Hold'em أم قواعد خاصة بنسخة كونكر القديمة.

الرسومات أصلية ومبنية من CSS وأيقونات/شخصيات عامة، ولا تحتوي أصولًا من كونكر.
